# Web3BridgeMax

Web3BridgeMax utilizes blockchain-agnostic architecture with real-time data processing and auto-scaling for high availability via API gateway.

With Web3BridgeMax, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/Web3BridgeMax.git`
2. `cd Web3BridgeMax`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
